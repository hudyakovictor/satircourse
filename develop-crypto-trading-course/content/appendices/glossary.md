# Приложение · Глоссарий трейдера без лишнего жаргона

Термин сначала объясняется простыми словами, затем — в рабочем значении. Если незнакомое слово встречается в уроке, сверяйтесь с этим глоссарием, а не пытайтесь угадывать по графику.

[[[Таблица / plain language cryptocurrency trading glossary ]]]]

| Термин | Простое объяснение | Рабочее значение в курсе |
|---|---|---|
| Агрессор (aggressor) | Участник, который принимает доступную цену. | Покупатель бьёт по ask, продавец — по bid. |
| Актив | То, чем торгуют. | Монета, токен или контракт. |
| Ask | Цена, по которой сейчас готовы продать. | Самый низкий ask — лучший ask. |
| Backtest | Проверка правила на исторических данных. | Учитывает только информацию, известную в момент решения, и реалистичные издержки. |
| ATR | Обычная ширина движения цены. | Average True Range: линейка стопа, не направление. |
| Base asset | Первый актив в паре. | В `ETH/USDT` это ETH; USDT — quote asset. |
| Bid | Цена, по которой сейчас готовы купить. | Самый высокий bid — лучший bid. |
| Bollinger Bands | Полосы Боллинджера. | Средняя и полосы стандартного отклонения; сжатие важнее простого касания границы. |
| Break of Structure (BOS) | Слом значимой структуры. | Например, LL ниже защищённого HL в восходящем тренде. |
| Breakout | Пробой важной зоны. | Торгуется после закрепления за уровнем либо по ретесту; есть инвалидация. |
| Bracket order | Связка входа, стопа и цели. | Упрощает исполнение плана; не гарантирует фактического исполнения (fill). |
| Candlestick | Свеча за период. | Показывает open, high, low, close. |
| Circulating supply | Токены в обращении. | Не равен max supply и не равен free float. |
| Close | Цена закрытия свечи. | Не равна гарантированной цене исполнения. |
| Crossover | Пересечение скользящих средних. | Трендовый сигнал, который без фильтра режима часто даёт ложные пересечения. |
| Корреляция | Склонность активов двигаться вместе. | В стресс-режиме повышается; риск считают по кластеру. |
| Drawdown | Снижение счёта от прошлого максимума. | Отслеживается в R и процентах. |
| Edge | Повторяемое торговое преимущество. | Положительное net expectancy в заданном режиме после издержек. |
| EMA | Экспоненциальная скользящая средняя. | Сильнее учитывает последние цены, чем SMA. |
| Expectancy | Математическое ожидание результата. | Считается в net R по выборке, а не «на глаз». |
| False breakout | Ложный пробой (фейк). | Цена вышла за зону и вернулась; первоначальная пробойная идея отменяется. |
| FDV | Fully Diluted Valuation. | Цена × полный ожидаемый supply. |
| Fill | Фактическое исполнение заявки. | Для журнала важнее желаемой цены. |
| Free float | Свободно обращающееся предложение. | Особенно важно для low-cap токенов и оценки ликвидности. |
| Funding payment | Периодический платёж по perpetual-контракту. | Рассчитывается по номиналу, funding rate и числу периодов; учитывается в net R. |
| Funding rate | Ставка фандинга в perpetual-контракте. | По ней рассчитывают периодический платёж между long и short. |
| Gross / net | До / после издержек. | В журнале ключевая метрика — net R. |
| Heikin Ashi | Синтетический вид свечей. | Может сглаживать тренд, но его цены не используют для исполнения и стопа. |
| Higher high (HH) | Максимум выше прошлого значимого максимума. | Часть восходящей структуры. |
| Higher low (HL) | Минимум выше прошлого значимого минимума. | Часть восходящей структуры. |
| Invalidation | Уровень отмены торговой идеи. | Основа stop-loss; определяется до входа. |
| Leading metrics | Опережающие метрики процесса. | Например, доля сделок по чек-листу; не путать с PnL. |
| Ликвидность | Возможность купить/продать без сильного сдвига цены. | Оценивается глубиной, спредом и объёмом. |
| Ликвидация | Принудительное закрытие маржинальной позиции. | Авария; не заменяет stop-loss. |
| Limit order | Лимитная заявка по заданной цене или лучше. | Защищает цену, но может не исполниться. |
| Long | Позиция на рост. | Прибыль при росте, убыток при падении. |
| Lower high (LH) | Максимум ниже прошлого значимого максимума. | Часть нисходящей структуры. |
| Lower low (LL) | Минимум ниже прошлого значимого минимума. | Часть нисходящей структуры. |
| Maker | Участник, добавивший ликвидность в стакан заявок. | Обычно использует limit order и платит свою комиссию. |
| Market order | Рыночная заявка на немедленное исполнение. | Получает доступную цену, а не гарантированную. |
| Margin | Средства, обеспечивающие позицию с плечом. | Не являются допустимым убытком: риск задаёт stop-loss. |
| Maintenance margin | Минимальная поддерживающая маржа. | При её нехватке биржа может ликвидировать позицию; правила зависят от площадки. |
| MACD | Индикатор разности двух EMA. | Гистограмма показывает расстояние MACD от сигнальной линии; дивергенция не является входом. |
| Market cap | Рыночная капитализация токенов в обращении. | Цена × circulating supply. |
| Mean reversion | Возврат цены к среднему. | Семейство стратегий для диапазона, не для сильного тренда. |
| No-trade | Осознанный отказ от сделки. | Полноценное решение с результатом 0R. |
| OCO | Два взаимоисключающих выхода. | Исполнение одного должно отменить другой. |
| OHLC | Четыре цены свечи. | Open, high, low, close. |
| OI | Open Interest, открытый интерес. | Объём открытых позиций по методике площадки. |
| On-chain | Данные, записанные в блокчейне. | Метрики требуют проверки методики и тренда, не одного дня. |
| Order book | Стакан заявок. | Снимок ожидающих заявок, не гарантия ликвидности. |
| Order flow | Поток исполненных сделок. | Помогает увидеть агрессора, но не предсказывает цену сам по себе. |
| Paper trading | Учебная торговля без реальных денег. | Исполняется по реальным правилам и издержкам. |
| Perpetual contract | Бессрочный деривативный контракт. | Для удержания учитывают funding rate, funding payment и правила маржи. |
| Playbook | Набор ограниченного числа карточек стратегии. | Каждая карточка содержит режим, сетап, триггер, риск и инвалидацию. |
| PnL | Profit and Loss, финансовый результат. | Оценивается после издержек; в курсе сопоставляется с первоначальным R. |
| Position size | Размер позиции. | Следствие риска и стоп-дистанции. |
| Pullback | Откат внутри движения. | Не равен развороту без BOS. |
| R | Единица планового риска. | Стоп = примерно −1R; выход +2R = две единицы риска. |
| R:R | Risk/reward ratio. | Соотношение потенциальной прибыли к риску; сравнивается с реализованным avg win. |
| Risk-off | Режим снижения аппетита к риску. | Корреляции альткоинов часто растут; кластерный риск пересчитывают консервативно. |
| Range | Боковой диапазон. | Имеет границы, середину и риск выхода. |
| Retest | Повторная проверка уровня после пробоя. | Возможный триггер, но не обязан произойти. |
| Risk of Ruin | Риск критически повредить капитал. | Зависит от edge, размера риска, серий и корреляций. |
| RSI | Relative Strength Index. | Осциллятор силы недавних движений; уровни 30/70 не являются кнопками входа. |
| Sentiment | Настроение рынка. | Контекст размера/осторожности, не самостоятельный вход. |
| Short | Позиция на падение. | Требует заёмного актива или дериватива; риск роста цены не ограничен. |
| Slippage | Проскальзывание. | Разница ожидаемой и фактической цены, особенно важна в тонком рынке и стресс. |
| SMA | Простая скользящая средняя. | Равный вес прошлым ценам в периоде. |
| Спред | Разница лучшего bid и ask. | Невидимая издержка входа/выхода. |
| Setup | Сетап, набор условий для одной сделки. | Содержит контекст, триггер, инвалидацию, риск и выход; не равен одному индикатору. |
| Squeeze | Сжатие волатильности. | Уменьшение диапазона перед возможным расширением; не даёт направление само по себе. |
| Stochastic Oscillator | Стохастик. | Сравнивает закрытие с диапазоном; лучше работает в боковом диапазоне, чем в сильном тренде. |
| Stop-loss | Стоп-лосс. | Закрывает ошибочную идею по структуре, а не по размеру боли. |
| Stop-market order | Стоп-заявка, активирующая рыночный ордер. | Повышает вероятность выхода, но не гарантирует точную цену в быстром движении. |
| Структура рынка | Последовательность экстремумов. | HH/HL или LH/LL на выбранном ТФ. |
| Swing high / swing low | Значимый локальный максимум / минимум. | Часто за ними лежит ликвидность; значимость зависит от ТФ. |
| Taker | Участник, забравший ликвидность из стакана заявок. | Обычно получает немедленное исполнение и платит свою комиссию. |
| Таймфрейм | Длина одной свечи. | Масштаб наблюдения, не скорость рынка. |
| Тейк-профит | Плановая фиксация прибыли. | Не отменяет необходимость следить за исполнением. |
| Token unlock | Разблокировка ранее заблокированных токенов. | Событие риска предложения, не автоматический сигнал. |
| Trigger | Условие, разрешающее вход. | Например, закрытие свечи за уровнем; не путать с причиной интереса. |
| TVL | Total Value Locked. | Прокси масштаба протокола, требующий проверки методики. |
| Vanity metrics | Тщеславные метрики. | Например, win streak; не подсказывают действие для улучшения процесса. |
| Volatility | Волатильность, амплитуда колебаний. | Определяет стоп-дистанцию и размер. |
| Win rate (WR) | Доля прибыльных сделок. | Нельзя оценивать отдельно от среднего выигрыша, среднего убытка и издержек. |

## Термины психологии и исследования

| Термин | Простое объяснение | Рабочее значение в курсе |
|---|---|---|
| Compliance | Соблюдение заранее записанного процесса. | Доля сделок, где выполнены правила входа, риска и журнала. |
| CPI | Consumer Price Index, индекс потребительских цен. | Макрособытие: важно время публикации и риск исполнения, а не угадывание направления. |
| Divergence | Расхождение цены и индикатора. | Предупреждение об ослаблении импульса, не самостоятельный сигнал на вход. |
| FOMO | Fear of Missing Out, страх упустить движение. | Психологический триггер для паузы и чек-листа. |
| In-sample / out-of-sample | Участки для настройки и честной проверки. | Параметры выбирают на in-sample и не меняют на out-of-sample. |
| Look-ahead bias | Ошибка заглядывания в будущее. | В историческом решении использованы ещё неизвестные на тот момент данные. |
| Momentum | Импульс цены. | Семейство индикаторов, измеряющих силу/скорость недавнего движения. |
| Order wall | Крупная видимая заявка в стакане. | Может быть снята; не является гарантированной поддержкой или сопротивлением. |
| Outlier | Выброс в выборке. | Не удаляется молча: проверяется, это ошибка исполнения или часть распределения. |
| Overtrading | Избыточная торговая активность. | Сделки вне сетапа; увеличивает издержки и процессные ошибки. |
| Price action | Чтение структуры и поведения цены. | Контекст для паттерна, триггера и инвалидации, а не «угадывание свечей». |
| Revenge trading | Попытка немедленно отыграть убыток. | Триггер для обязательной паузы, не новая стратегия. |
| RoR | Risk of Ruin. | Сокращение для оценки риска критически повредить капитал. |
| Tilt | Состояние потери дисциплины после эмоции. | Срабатывает предохранитель: стоп торговли, журнал, пауза. |
| Walk-forward | Последовательная проверка на новом участке. | Параметры не меняют между train и test. |

## Три вопроса к любому новому термину

1. **Что он измеряет?** Например, ATR измеряет диапазон, не направление.
2. **Чего он не измеряет?** Funding не предсказывает следующую свечу.
3. **Какое решение он может изменить?** Например, высокий funding rate может уменьшить размер или запретить удержание через выходные.
