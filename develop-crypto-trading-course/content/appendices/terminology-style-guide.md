# Приложение · Терминологический стандарт курса

Этот стандарт применён при редактуре всех модулей, шаблонов и приложений. Цель — не русифицировать профессиональный язык любой ценой, а дать новичку одно понятие, одно устойчивое название и одно объяснение.

## Правило выбора термина

1. **Есть устоявшийся русский термин — используем русский.** Примеры: стакан заявок, лимитная заявка, рыночная структура, проскальзывание, ложный пробой (фейк), стоп-лосс, поддержка, сопротивление, объём.
2. **Английская форма является отраслевым стандартом или перевод неоднозначен — оставляем English.** Примеры: bid, ask, market order, limit order, funding rate, open interest, on-chain, edge, fill, swing high, squeeze, walk-forward.
3. **При первом появлении даём обе формы:** `русский термин (English term)` либо `English term — русское объяснение`. Дальше не меняем форму без причины.
4. **Служебные визуальные пометки — исключение:** всё после `/` в `[[[Тип / prompt ]]]]` намеренно остаётся на английском для будущей генерации визуала.

## Канонические варианты

| Понятие | Форма в курсе | Не использовать как основную форму |
|---|---|---|
| Книга заявок | стакан заявок (order book) | «книга» без уточнения, depth-wall |
| Немедленное исполнение | рыночная заявка (market order) | «маркет» без слова «заявка» в объяснении новичку |
| Исполнение по цене | лимитная заявка (limit order) | «лимит» как синоним стопа |
| Реальная цена исполнения | фактическое исполнение (fill) | «цена на графике» как fill |
| Направление позиции | long / short / no-trade | «войти куда-нибудь», «поймать движение» |
| Ложный пробой | ложный пробой (фейк, false breakout) | фейкаут без пояснения |
| Сжатие волатильности | сжатие волатильности (squeeze) | сквиз без объяснения |
| Экстремумы | swing high / swing low | свинг-хай/свинг-лоу без расшифровки |
| Пересечение MA | пересечение скользящих средних (crossover) | кроссовер без контекста |
| Отмена идеи | инвалидация (invalidation) | «рынок неправ» |
| Данные сети | on-chain-метрики | ончейн без пояснения при первом появлении |
| Разблокировка токенов | token unlock | разлок |
| Свободное обращение | free float | «низкий float» без пояснения |
| Ставка фандинга | funding rate | funding как неопределённый «сигнал» |
| Платёж фандинга | funding payment | funding, если речь о расходе или доходе позиции |
| Бессрочный контракт | perpetual contract | «перп» в объяснении новичку |
| Торговая конструкция | сетап (setup) | «сигнал» без контекста, риска и инвалидации |
| Историческая проверка | бэктест (backtest) | тест с будущими данными или без издержек |
| Открытый интерес | open interest (OI) | OI без расшифровки при первом появлении |
| Проверка на будущем участке | walk-forward | walkforward, «тест из будущего» без метода |
| Качество процесса | соблюдение/нарушение процесса | process-pass/process-fail в тексте для ученика |
| Опережающие показатели | leading metrics | телеметрия решений, когда имеется в виду KPI процесса |

## Проверка перед публикацией нового урока

- [ ] Новый термин есть в [глоссарии](glossary.md) или расшифрован при первом появлении.
- [ ] Одно понятие не названо тремя синонимами в одном модуле.
- [ ] Термин отражает механику, а не маркетинговую метафору.
- [ ] Слово из интерфейса биржи сохранено на английском, если его русский перевод может не совпасть с кнопкой пользователя.
- [ ] Нет жаргона, который маскирует действие: вместо «поймать нож» в инструкции пишется «входить до стабилизации запрещено».

## Результат аудита

Во время редакции согласованы термины **ложный пробой (фейк)**, **сжатие волатильности (squeeze)**, **пересечение скользящих средних (crossover)**, **критическая ошибка** и **метрики процесса**. Оставлены привычные русскоязычному трейдингу формы; уточняющие English-термины даны там, где они помогают сопоставить правило с интерфейсом или источником данных.
