# Приложение · Рубрики освоения для всех 100 уровней

Рубрика делает проверку воспроизводимой: **артефакт** — что ученик сдаёт, **зачёт** — наблюдаемое условие, **критическая ошибка** — ошибка, после которой уровень не засчитывается даже при случайном плюсе. Она дополняет [Э], но не меняет уроки и их порядок.

## Модуль A · Основы биржевой торговли

| Уровень | Артефакт | Зачёт | Критическая ошибка |
|---|---|---|---|
| A0 | Размеченная лента из 20 сделок | Агрессор назван без прогноза цены | «Зелёные сделки гарантируют рост» |
| A1 | Очередь четырёх заявок | Верны цена, затем время | Игнорирование ценового приоритета |
| A2 | Выбор long/short/no-trade | Есть причина и риск направления | Вход без сетапа |
| A3 | Выбор заявки в двух кейсах | Назван обмен скорость/цена | Limit order назван гарантированным стопом |
| A4 | Расчёт пяти net-результатов | Все издержки учтены | Оценка только gross PnL |
| A5 | Два стопа при разных ATR | Размер меняется, риск нет | Один стоп для любого режима |
| A6 | Подписанный экран терминала | Bid/ask/лента/стакан названы | Стена принята за гарантию |
| A7 | Полная запись paper trading | Есть стоп, фактическое исполнение (fill) и скрины | Сделка без стопа |
